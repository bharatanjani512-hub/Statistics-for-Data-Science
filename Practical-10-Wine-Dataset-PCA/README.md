# Practical 10: Wine Dataset Analysis and Principal Component Analysis (PCA)

## Objective
To analyse the Wine dataset using descriptive statistics, visualizations, covariance, feature scaling and Principal Component Analysis.

## Topics Covered
- Loading the Wine dataset
- Basic statistical description
- Boxplots by wine class
- Scatterplot using two variables
- Covariance matrix and heatmap
- Feature scaling using StandardScaler
- Dimensionality reduction using PCA
- Visualizing wine class separation
- Explained variance ratio

## Dataset
Wine dataset loaded using Scikit-learn.

## Files
- `practical10.py` - Python implementation
- `output/boxplots_by_class.png` - Boxplots by class
- `output/scatterplot_two_variables.png` - Scatterplot
- `output/covariance_matrix.png` - Covariance heatmap
- `output/pca_class_separation.png` - PCA visualization

## Tools Used
Python, Pandas, Matplotlib, Seaborn, Scikit-learn
