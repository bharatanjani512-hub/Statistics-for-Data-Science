# Statistics for Data Science

This repository contains practical assignments and lab work completed as part of my **MSc Data Science** program.

The practicals focus on applying statistical and data science concepts using Python and commonly used data science libraries.

## Course

**Subject:** Statistics for Data Science  
**Program:** MSc Data Science  
**University:** Shoolini University

## Practical Work

### Practical 1 - Revisiting Pandas and NumPy

This practical covers the basic concepts of Pandas and NumPy and includes:

- Creating raw student data
- Converting raw data into a Pandas DataFrame
- Understanding DataFrame structure and data types
- Creating NumPy matrices
- Finding shape, size, and dimensions of arrays
- Performing matrix operations
- Matrix addition and subtraction
- Element-wise multiplication
- Matrix multiplication
- Matrix transpose
- Matrix inverse
- Converting categorical data into numerical data
- Understanding One-Hot Encoding

### Files

The Practical 1 folder contains:

- `practical1.py` - Python implementation of the practical
- `Lab Manual - Practical 1 - Revisiting Pandas and NumPy.pdf` - Complete lab manual with problem statement, solution, code, outputs, and conclusion
