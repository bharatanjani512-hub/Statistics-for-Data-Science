# Statistics for Data Science

This repository contains practical assignments completed as part of the MSc Data Science programme at Shoolini University.

The practicals use Python and commonly used data science libraries to explore statistical concepts, analyse datasets, perform hypothesis testing, build machine learning models and visualize results.

## Course Information

- **Programme:** MSc Data Science
- **Subject:** Statistics for Data Science
- **University:** Shoolini University
- **Language:** Python

## Practical Work

| No. | Practical | Main Topics |
|---|---|---|
| 1 | [Revisiting Pandas and NumPy](Practical-1-Revisiting-Pandas-and-NumPy/README.md) | DataFrames, arrays, matrix operations, One-Hot Encoding |
| 2 | [Understanding Foundation of Statistics Using Rating Dataset](Practical-2-Understanding-Foundation-of-Stats-using-Rating-Dataset/README.md) | Dataset exploration and basic statistics |

| 4 | [Understanding Data with Graphs](Practical-4-Understanding-Data-with-Graphs/README.md) | Data visualization and graphical analysis |
| 5 | [Understanding Two-Tailed Test](Practical-5-Understanding-Two-Tailed-Test/README.md) | Probability and hypothesis testing |
| 6 | [Understanding T-Test, ANOVA and Chi-Square](Practical-6-Understanding-T-Test-ANOVA-Chi-Square/README.md) | T-test, ANOVA, Chi-square and correlation |
| 7 | [Understanding Regression with T-Test and ANOVA](Practical-7-Understanding-Regression-with-T-Test-and-ANOVA/README.md) | OLS regression and ANOVA |
