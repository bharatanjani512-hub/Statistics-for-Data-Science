# Practical 8: Decision Trees and Its Maxdepth

## Objective
To build and evaluate a Decision Tree classifier using the Pima Indians Diabetes dataset.

## Topics Covered
- Dataset loading and feature selection
- Independent and dependent variables
- Train-test split
- Entropy calculation
- Information Gain
- Gini Index and Gini reduction
- Root node selection
- Decision Tree classification
- Maximum depth comparison
- Decision Tree visualization
- Model accuracy and classification report

## Dataset
Pima Indians Diabetes dataset (`diabetes.csv`).

The Python script loads the dataset from `data/diabetes.csv`.

## Files
- `practical8.py` - Python implementation
- `data/diabetes.csv` - Dataset
- `decision_tree_visualization.png` - Decision Tree visualization

## Tools Used
Python, Pandas, Scikit-learn, Matplotlib
