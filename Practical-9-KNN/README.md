# Practical 9: K-Nearest Neighbours (KNN)

## Objective
To implement the K-Nearest Neighbours algorithm using the Iris dataset and evaluate its classification performance.

## Topics Covered
- Exploratory Data Analysis
- Feature selection
- Train-test split
- Feature scaling using StandardScaler
- KNN model training
- Prediction and confusion matrix
- Accuracy, precision, recall and F1-score
- Error-rate comparison for different K values
- Selection of the best K
- Visualization of classification results

## Dataset
Iris dataset loaded using Scikit-learn.

## Files
- `practical9.py` - Python implementation
- `output/error_rate_vs_k.png` - Error-rate graph
- `output/confusion_matrix.png` - Confusion matrix visualization
- `output/test_results_visualization.png` - Test result visualization

## Tools Used
Python, Pandas, Matplotlib, Scikit-learn
