# Practical 1: Revisiting Pandas and NumPy

## Objective
To understand Pandas DataFrames, NumPy arrays, and basic matrix operations using Python.

## Topics Covered
- Creating and manipulating Pandas DataFrames
- Understanding rows, columns, shape, size, and dimensions
- Creating NumPy matrices
- Matrix addition and subtraction
- Element-wise multiplication and matrix multiplication
- Matrix transpose and inverse
- Converting categorical data using One-Hot Encoding
